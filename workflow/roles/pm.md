### F-001: 知识点体系

```
小学数学知识点树（示例）

一年级
├── 数与运算
│   ├── 10以内加法
│   ├── 10以内减法
│   ├── 20以内加法（进位）
│   └── 20以内减法（退位）
└── 应用题
    └── 简单加减应用

二年级
├── 数与运算
│   ├── 100以内加法
│   ├── 100以内减法
│   └── 连加连减
└── 应用题
    └── 两步计算应用

...

六年级
├── 数与运算
│   ├── 分数乘法
│   ├── 分数除法
│   ├── 百分数
│   └── 比例
└── 应用题
    └── 比例应用
```

### F-002: 薄弱点诊断算法

```
输入: 用户历史答题记录
输出: 薄弱知识点列表

算法:
1. 按知识点分组统计正确率
2. 正确率 < 60% → 薄弱点
3. 正确率 60-80% → 待加强
4. 正确率 > 80% → 已掌握

权重:
- 最近7天的记录权重更高
- 错题重做正确可恢复部分分数
```

### F-003: 智能推题策略

```
策略1: 薄弱点优先
- 70% 题目来自薄弱知识点
- 30% 题目来自已掌握（保持）

策略2: 难度递进
- 连续3题正确 → 难度+1
- 连续2题错误 → 难度-1

策略3: 避免重复
- 同一题目不重复出现
- 同一题型间隔至少5题
```

## 💡 产品思考

### 用户画像
1. **学生**: 6-12岁小学生，需要趣味性和成就感
2. **家长**: 关注学习效果，需要可视化的报告
3. **老师**: （未来）班级管理，批量布置作业

### 核心价值主张
1. **精准诊断**: 知道孩子哪里不会
2. **个性提升**: 针对薄弱点练习
3. **可视化**: 学习进步看得见
4. **持续激励**: 让孩子愿意坚持

### 差异化竞争
1. **知识点细分**: 比同类产品更细的知识点拆分
2. **遗忘曲线**: 基于艾宾浩斯的复习提醒
3. **智能推题**: 不做无效重复，精准提升
4. **免费+增值**: 基础功能免费，高级报告收费

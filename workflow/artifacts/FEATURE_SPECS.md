### 2. 薄弱点诊断

### 2.1 功能描述
基于用户答题历史，智能诊断薄弱知识点，提供针对性练习建议。

### 2.2 诊断算法

```python
# 薄弱点判定标准
def diagnose_weakness(user_history):
    results = {}
    for topic in all_topics:
        records = get_records(user_history, topic)
        if len(records) < 5:
            continue  # 样本不足

        accuracy = calculate_accuracy(records)
        recent_accuracy = calculate_recent_accuracy(records, days=7)

        # 综合评分 = 历史正确率 * 0.3 + 近期正确率 * 0.7
        score = accuracy * 0.3 + recent_accuracy * 0.7

        if score < 60:
            results[topic] = "薄弱"
        elif score < 80:
            results[topic] = "待加强"
        else:
            results[topic] = "已掌握"

    return results
```

## 🚀 P1 重要功能

### 5. 智能推题

### 5.1 功能描述
基于薄弱知识点，智能推荐练习题目。

### 5.2 推题策略

```
策略1: 薄弱点优先
- 70% 题目来自薄弱知识点
- 30% 题目来自已掌握（保持）

策略2: 难度递进
- 连续3题正确 → 难度+1
- 连续2题错误 → 难度-1

策略3: 避免重复
- 同一题目不重复出现
- 同一题型间隔至少5题
```

### 5.3 验收标准
- [ ] 根据薄弱点推荐题目
- [ ] 难度自适应调整
- [ ] 避免重复题目
